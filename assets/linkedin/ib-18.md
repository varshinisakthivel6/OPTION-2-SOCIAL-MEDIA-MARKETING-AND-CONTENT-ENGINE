# IB-18 — A useful content brief can fit on one page.

Platform: LinkedIn
Format: Text post
Pillar: Audience growth

## Hook
A useful content brief can fit on one page.

## Caption / script
Write down the target audience, problem, one-sentence promise, three key points, proof or example, and one CTA. This small brief helps avoid vague posts.

## CTA
