
## What is included

* Streamlit content-draft generator (offline deterministic template mode).
* Input: pasted/uploaded TXT or Markdown.
* Output: platform-specific draft hooks, captions, CTAs and UTM links; CSV/JSON download.
* Basic quality checks, duplicate detection, error logging and CSV upsert.
* 30 editable content drafts across Instagram, LinkedIn and YouTube Shorts.
* Editable SVG graphics/carousel templates and silent text-preview MP4s where generated.
* Draft calendar, strategy, launch kit, audit worksheet and audience-test templates.
* Supplied assessment workbook with asset rows inserted.
